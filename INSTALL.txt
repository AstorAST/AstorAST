# AstorAST GitHub Profile

Put these files in the profile repository:

    AstorAST/AstorAST

Keep README.md at the repository root and keep the assets folder beside it.

The visual sections are self-contained animated SVGs. No JavaScript is required.
The GitHub contribution graph is loaded from an external service; remove that image if you prefer a fully self-hosted profile.

If the GitHub username is different, replace AstorAST in the contribution graph URL in README.md.
