# ASTteam Marathon GitHub Profile

Replace the contents of the ASTteam profile repository with this package.

The design is intentionally animation-first:
- continuous marathon runner motion
- moving race lanes and dash lines
- animated checkpoints
- telemetry / lap progression
- moving finish-line scan
- ambient motion and pulsing status indicators

All main visual panels are local SVG files with SVG animation, so no custom CSS or JavaScript is required.

GitHub may sanitize or limit some SVG features depending on where an SVG is rendered. The core SMIL animations used here are designed to work as image embeds.
